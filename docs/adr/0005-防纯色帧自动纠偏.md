# 防纯色帧自动纠偏：双信号判定 + 向后微调 + 严格模式

## 背景

ep01 初批 25 条截图实测中，`at` 精确命中了**纯色转场帧**：`00:02:45` 落在黑场（连续 ~1s YAVG=16，165.00 为黑场末帧）、`00:05:31` 落在频闪白帧（331.00 YAVG=235，该段每隔数帧闪白一次）。两条产物都是 12KB 的纯色图，可用性为零。

关键区分：这**不是精度问题**——帧级精确（ADR-0004，`-ss` 置后）工作正常，是**时间点自身落在无内容帧**上。此前对策是人工发现 → 手工改时间戳，不可规模化（25 条里 2 条中招，8%），且用户无法事前预知。

候选方案与权衡：
- **连拍前 N 帧供挑选**：打破"截图 = 单时间点一帧"的领域契约，产物爆炸（×N），被否决。
- **输入 seek 吸附关键帧**：回到 ADR-0001 否掉的路径，误差达 ±4~7s，绝不可接受。
- **内容判定 + 自动纠偏**：保持对外契约（一个 `at` → 一张图），把"多帧"做成内部机制。采纳。

## 决策

- **判定信号 = YAVG + YSTD 双信号**：亮度均值处于极端区间（黑 ≈0/16、白 ≈235/255）**且**标准差趋零（整帧像素几乎相同）→ 判为纯色帧。单用 YAVG 会误杀正常夜景/高光场景；YSTD 才是"整帧纯色"的本质信号。
- **只防纯色帧**；静帧（有内容但静止的画面）**不判坏**——它截出来完全可用。不做帧间差异检测（实现重，且真实快速转场会误报）。
- **纠偏 = 向后逐帧搜索**：黑场/频闪之后通常是内容恢复；"稍晚取帧"比"回到过去"更可预期。窗口上限 **64 帧（≈2.56s）**（实测黑场 1s ≈ 25 帧、频闪区 0.5s ≈ 13 帧，64 帧留足余量）；**出窗无有效帧 → 按严格模式单条报错**，不悄悄输出远处帧。
- **默认开启自动纠偏**，`--strict` flag 关闭：严格模式判坏即单条报错、跳过该条、继续其余、退出码非零汇总。
- **规格回写？不**。`frames.json` 保持用户意图时刻（`at`），产物命名不变（`ep01-f12.jpg`），实际取帧时刻**记录在日志**（含偏移量）。复现一致性由**确定性算法**保证：相同 `at` + 相同判定 → 相同输出，不依赖会话记忆。
- **`--dry-run` 增加纯色帧预警**：执行前逐条检测 `at` 是否触发纠偏，打印"将纠偏至 ~00:02:46.120"。
- 实现为纯函数模块（`isSolidFrame` + 纠偏搜索），与 `framespec.ts` 同等可测；测试覆盖：黑/白判定、暗场景不误杀、纠偏命中、出窗报错、`--strict` 行为。
- `frames.json` schema **不变**。

## 后果

- 默认路径下用户无需关心转场帧：25 条重跑预期 f12/f25 自动纠偏（向后 ~1s / 数十帧），其余 23 条 `at` 本身有效、零偏移。
- `--strict` 给"该时刻必须原样"的场景兜底，代价是判坏即报错。
- "截图产物与其来源时间点一一对应"规则软化为"产物对应规格 `at`，实际取帧可能略晚并记录"——已同步更新 CONTEXT.md。
- 纠偏输出的帧质量：向后窗口内第一个有效帧已过淡入/频闪主体，画面完整可用；若淡出→黑场→淡入的结构（f12 处是 fade 到舞台黑场再淡入），首个有效帧可能在淡入早期，亮度略暗，属已知可接受折衷（用户可通过改 `at` 精细控制）。
- 判定阈值（YAVG 极端区间、YSTD 下限）先固定，若未来遇到判错案例再参数化（与 ADR-0004 质量参数同策略：够用再提）。
## 实现注记（本提交落地）

- **YSTD → YMAX-YMIN 近似**：`signalstats` 在本机 ffmpeg（n9.0.1, 2026-08-29 构建）上不输出 YSTD，"标准差趋零"以全帧亮度范围 `YMAX - YMIN ≤ 16` 实现（整帧像素几乎相同 ⇔ 范围 ≈ 0，与 YSTD 是同一测量对象）。
- **探测方式 = 先抽帧成图、再单独探测图片**：本构建中 `-ss` 输出 seek 若与 filtergraph（哪怕只有 `metadata=print`）组合，会从片头解码并输出错误帧（实测解码 4127+ 帧、耗时 17~37s、写出错误图像）；纯抽帧路径（无 `-vf`）帧级精确，图片级 signalstats 探测单张约 0.08s。
- **纠偏窗口一次解码抽取**：`-ss at -frames:v 65`（无 filter）一次解码取出 `at`..`at+2.56s` 共 65 帧，输出文件序号即相对 `at` 的帧号（`f-01` = `at` 帧、`f-(k+1)` = 第 k 帧后），逐张探测首个有效帧；比逐帧 seek 至少快一个量级。
- **实测重跑 ep01（25 条）**：f12（00:02:45 黑场）自动纠偏至 00:02:45.040（+1 帧，YAVG 0 → 146.39）、f25（00:05:31 频闪白）自动纠偏至 00:05:31.040（+1 帧，YAVG 235 → 173.93）；其余 23 条 `at` 本身有效、零偏移；`--strict` 单条实测判坏即报错、不产出、退出码 1。dry-run 耗时 ~94s（25 条逐条探测），单条纠偏 ~4s。
- ep01 的 `frames.json` 中 f12/f25 曾被手工 +1s 改为 00:02:46/00:05:32 规避纯色帧（正是本 ADR 要消灭的做法），本次恢复意图时刻 00:02:45/00:05:31，交由自动纠偏处理；schema 不变。
