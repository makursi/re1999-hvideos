# 三段式媒体目录与项目级泛化（ADR-0009）

## 背景

项目定位原为"《重返未来：1999》官方短片专用"：`media/raw`（只读素材）→ 规格 + CLI → `media/exports`（剪辑）/`media/screenshots`（截图），且 ADR-0003 规定"**产物与规格同目录**"（`manifest.json`/`frames.json` 跟随该集产物目录）。定位放宽为**通用媒体工具**（任意素材项目均可剪辑/截图）后，现有布局有两个问题：

1. 没有显式的"输入 → 操作 → 输出"分层，规格与产物混在同一目录树上，无法表达"素材与配方分离、产物可再生"的语义；
2. 全部硬编码 1999 形态：`media/raw`、`epN` 单元层、`RE1999_EXPORTS_DIR`/`RE1999_SCREENSHOTS_DIR` 扫描基准 —— 换一个素材项目无法复用。

事实约束：素材 `source` 路径是版本化规格里的**数据**不是配置（ADR-0007）；`media` 下产物（mp4/jpg/png/webp）一律不进 git（.gitignore）；CLI 是 `re1999 clip|snap` 双子命令（ADR-0006）；discovery 目前只认 `<基准>/epN/<规格>` 一层。

## 决策

- **三段式布局（输入 → 操作 → 输出）**：
  - `media/input/<项目>/` — 只读原始素材（videos/、audios/…），不入 git；每个项目一份 `README.md` 锚定并记录中文映射；
  - `media/work/<项目>/<类>/<单元>/` — 规格（操作定义）：`clips/<单元>/manifest.json` 与 `screenshots/<单元>/frames.json`，**进 git**；
  - `media/output/<项目>/<类>/<单元>/` — 产物（不入 git）；
  - `media/temp/` — 临时工作区，不属于三层。
- **项目层 + 单元术语**：CLI 增加可选 `--project <name>`（缺省 = 全部项目），`list` 按 项目→单元 两级展示；第二层单位术语从"集（episode）"统一为"**单元（unit）**"，旗标 `--ep` 更名 `--unit`（概念级泛化：1999 的单元目录名与规格 id——`ep1`~`ep7`、`ep01-f01`——是该项目的私有数据，不重命名）。
- **产物默认 = work→output 镜像**：规格在 `media/work/<项目>/<类>/<单元>/x.json`，产物默认落 `media/output/<项目>/<类>/<单元>/`（同一相对路径、把 work 根换成 output 根）。**取代 ADR-0003 的"产物与规格同目录"**；显式覆盖（snap 的 `dir`、clip 的 `-o`）仍然优先。规格位于 work 根之外时（显式单文件模式）回退到规格自身目录。
- **配置面修订（ADR-0007）**：旋钮更名 `RE1999_EXPORTS_DIR`→`RE1999_WORK_DIR`（规格扫描根）、`RE1999_SCREENSHOTS_DIR`→`RE1999_OUTPUT_DIR`（产物默认根）、`RE1999_TEMP_DIR` 不变；**不设 input 旋钮**——素材 `source` 路径是规格数据，延续 ADR-0007 立场。
- **discovery 两层扫描**：`<work>/<项目>/<类>/<单元>/<规格>`，项目按 ASCII 字典序、单元按数字排序（沿用原 `ep1 < ep2 < ep10` 语义）。
- **现有 1999 资产全量迁移、零删除零转码**：素材移入 `media/input/1999/`，规格 git mv 至 `media/work/1999/`，版本化规格的 `source` 改写为 `media/input/1999/videos/…`；旧 `media/raw`/`media/exports`/`media/screenshots`/`media/clips`/`media/processed` 骨架删除。
- **仓库标识不变**：仓库名、包名、CLI 程序名 `re1999` 保持原样（定位放宽不改名）。

## 后果

- 任意素材项目可复用管线：`media/input/<新项目>/` 放素材 → `media/work/<新项目>/<类>/<单元>/` 写规格 → 产物自动落 `media/output/<新项目>/…`；旧环境变量名失效（本地项目、0.x，破坏性可接受）。
- `verify-exports.mjs`、README、技能、AGENTS.md、CONTEXT.md 全部按新布局同步；`.gitignore` 改为 input 二进制忽略 + work 规格保留 + output 全忽略。
- 版本号对齐：本迭代为 0.3.0（CHANGELOG 已记 0.2.0，package.json 此前滞留在 0.1.0）。
- 后续若需把 `media/` 根整体搬离（换素材盘等），仍属"改写版本化规格数据"范畴，不在配置面内解决。
